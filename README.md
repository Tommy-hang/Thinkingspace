# ThinkingSpace

> 让 AI 对话从一条时间线，变成一个可以探索的思维空间。

当前版本：**V0.3 — Personal Daily Driver**

---

## 一分钟启动（复制即可）

在项目文件夹中打开终端（VS Code：终端 → 新建终端），依次执行：

```bash
npm install
```

```bash
npm run dev
```

然后浏览器打开：

```text
http://localhost:5173
```

第一次打开会看到一个内置示例项目「Transformer 学习」，可以直接点击卡片体验。

---

## 你会看到什么

| 区域 | 作用 |
| --- | --- |
| 顶部栏 | 切换 / 新建项目，搜索，整理布局，导入导出，深浅色，设置 |
| 左侧栏 | 项目概述、按状态筛选、主题结构树 |
| 地图（Map） | 无限画布，每个节点是一个「主题卡片」，可拖动、缩放、平移 |
| 聚焦视图（Focus） | 点击卡片后全屏进入，在主题内部与 AI 对话 |

---

## 核心操作

- **新建主题**：顶部栏「新主题」，或地图空白处「创建第一个主题」。
- **进入主题**：单击任意卡片 → 全屏 Focus View。
- **创建分支**：在 Focus View 中选中任意文字 → 点「分支」，即可从这句话生长出一个新的子主题（会记录锚点）。
- **整理布局**：顶部栏「整理布局」，一键排成清晰的树形结构。
- **搜索**：顶部栏「搜索」或按 `Ctrl + K`，可搜索主题标题、摘要和全部对话内容。
- **节点状态**：每个主题可设为 进行中 / 探索中 / 已收敛 / 暂搁置，并在左侧栏筛选。
- **导入导出**：顶部栏下载图标 → 导出当前项目 / 全部项目，或导入 `.thinkingspace.json`。

## 接入真实 AI（DeepSeek）

1. 点击右上角齿轮 → 设置。
2. 在 **AI Providers** 中找到 DeepSeek，填入你的 API Key。
3. 点「设为当前」。
4. 回到主题中提问，即可看到模型流式回答。

未配置 Key 时，默认使用「离线演示」模式，界面流程完全可用，但回答是预设文本。

**API Key 只保存在你自己的浏览器里，不会被导出，也不会进入 Git 仓库。**
