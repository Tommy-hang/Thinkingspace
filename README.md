# ThinkingSpace

> 把 AI 对话从一条时间线，变成一个可以探索的思维空间。

**在线体验**：https://tommy-hang.github.io/Thinkingspace/

当前版本：**V0.3.6**

---

## 这是什么

传统 AI 聊天是一条不断向下滚动的消息流。当你对回答里的某个概念产生疑问，追问几轮之后，原来的主线早已消失在屏幕上方。

ThinkingSpace 换了一种结构：

- **Topic** —— 每个认知主题是一张卡片，而不是一条消息
- **Branch** —— 从某句话继续深入，会长出一个新的子主题，并记住它来自哪句话
- **Map** —— 所有主题构成一张可导航的地图，而不是一条时间线
- **Focus** —— 点开卡片进入沉浸式对话，返回后地图的缩放与位置保持不变

它保存的不是「我和 AI 说过什么」，而是「我是怎样想到这里的」。

| 传统 AI Chat | ThinkingSpace |
| --- | --- |
| 时间优先 | 结构优先 |
| 滚动 | 导航 |
| 历史 | 空间 |
| 继续往下聊 | 深入 / 分支 / 跳转 / 收敛 |

## 核心能力

### 空间化的思考

| 能力 | 说明 |
| --- | --- |
| **Conversation Map** | 无限画布，主题卡片可拖动、缩放、平移 |
| **Topic Card** | 显示标题、摘要、状态、对话轮数、分支数、待解决问题数 |
| **Focus View** | 全屏沉浸对话，带从卡片展开的空间过渡 |
| **Branch** | 选中回答里的任意文字即可创建子主题，并保留锚点 |
| **Branch Intent** | 创建分支时选择思考方式：深入解释 / 为什么 / 举例 / **反例** / 建立联系 / 自定义 |
| **子树折叠** | 暂时收起某个主题的全部后代，地图不被撑爆 |
| **隐藏与恢复** | 隐藏某张卡片（连带其子分支），可在左侧主题树里恢复 |
| **思考路径高亮** | 选中深层主题时，它的祖先链被强调，一眼看清来路 |
| **悬停预览** | 鼠标停留即可看到摘要与最后一段回答，不用点进去 |
| **自动布局** | 一键排成整齐的树形结构（只排列当前可见节点） |

### 结构化的上下文

| 能力 | 说明 |
| --- | --- |
| **Context Engine** | 利用树结构构建上下文：项目概述 → 上层主题摘要 → 当前主题对话 → 锚点 → 问题。**不会把全部历史发给模型** |
| **Branch Context** | 分支会携带它诞生时的那句话，模型因此知道「你在问哪一句」 |
| **@ 引用主题** | 输入 `@` 引用同项目内的其它主题，只发送它的「当前理解」 |
| **联网搜索** | 可选开启，提问前先检索网页，回答下方列出参考来源 |

### 收敛与整理

| 能力 | 说明 |
| --- | --- |
| **当前理解** | 每个主题由 AI 总结出的结论性概述，可随时重新生成 |
| **综合理解** | 当主题有 2 个以上子分支时，把它们**收敛**成一段更高层的理解 |
| **待解决问题** | 记录还没搞懂的问题，**全项目共享一份清单**，点击可跳回创建它的卡片 |
| **探索方向建议** | 每次回答后 AI 提议 2–4 个值得继续的方向，**只有你点击才会创建分支** |
| **知识地图** | 由全部卡片的「当前理解」生成整个项目的**知识点思维导图**，知识点下方标注来源卡片并可点击定位，支持导出 PDF |
| **Markdown 导出** | 把某个主题连同其所有子分支导出成一篇文章 |

### AI 能力

- **多模型切换**：DeepSeek-V4.1-Flash / V4-Pro 等，也支持自定义模型名
- **深度思考**：可开关，并可调思考强度（低 / 高 / 最高）
- **流式输出**：逐字生成，可随时停止
- **Markdown + KaTeX**：标题、列表、表格、代码高亮、行内与块级公式全部正确渲染
- **多 Provider**：DeepSeek / OpenAI / OpenRouter / 任意 OpenAI 兼容接口
- **离线演示模式**：不配置任何 Key 也能完整体验界面与流程

### 日常使用

项目管理 · 全局搜索（`Ctrl + K`）· 节点状态与筛选 · 最近浏览 · 收藏 ·
主题直链（可复制、可分享到同一设备）· 撤销重做 · 编辑提问并重新生成 ·
导入导出 · 使用说明面板 · 深浅色主题

## 快速开始

在项目文件夹中打开终端（VS Code：终端 → 新建终端），依次执行：

```bash
npm install
```

```bash
npm run dev
```

然后浏览器打开：

```text
http://localhost:5173
```

第一次打开会看到内置示例项目「Transformer 学习」，可以直接点击卡片体验。

---

## 接入真实 AI

1. 点击右上角齿轮 → 设置
2. 在 **AI Providers** 中找到 DeepSeek，填入你的 API Key
3. 点「设为当前」
4. 回到主题中提问，即可看到模型流式回答

**联网搜索**（可选）：在设置 →「联网搜索」里填入 Tavily / Exa / Serper 的 Key，
然后在输入框上方打开 🌐 开关。

> 未配置 Key 时，默认使用「离线演示」模式，界面流程完全可用，但回答是预设文本。

---

## 数据与隐私

- 所有内容保存在**你自己浏览器的 `localStorage`** 中，没有后端、没有账号
- **API Key 单独存放**（键名 `thinkingspace.secrets.v1`），不参与导出，也不会进入 Git 仓库
- 导出的 `.thinkingspace.json` **只包含项目内容**
- ⚠️ 清理浏览器数据、更换浏览器或更换电脑都会导致内容不可见，**请定期导出备份**

## 设计原则

1. **AI 提议，用户决定。** AI 不会自动创建节点、自动连线或自动重构地图。
2. **内容优先，低视觉噪声。** 地图是为思考服务的，不是为炫技服务的。
3. **上下文要精准，而不是越多越好。** 只发送与当前主题真正相关的内容。
4. **数据属于你。** 本地存储、密钥不上传、随时可完整导出。
